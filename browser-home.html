Wiza extraction * automation profile

This is the automation browser.

Keep it separate from your everyday Chrome. The script drives this window and only this window.

  1. Sign in to LinkedIn Use the account you have set aside for this work.
  2. Install the Wiza extension and sign in to it Chrome Web Store -> Wiza
  3. Open any LinkedIn profile Any one will do.
  4. Open the Wiza side panel and pin it The pin icon in the panel's header. The script reads that panel - if it is closed, there is nothing to read. Leave it pinned.
Done all four? Back in the terminal, run .\.venv\Scripts\python.exe doctor.py - it confirms the LinkedIn session and whether the side panel is actually visible to the script.
You only sign in once. This profile keeps both logins permanently, across reboots and every future run. Lost this window? Run show-browser.ps1.
